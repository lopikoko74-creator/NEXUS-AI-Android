# NEXUS AI — Android

Локальный голосовой агент для Android 16. Целевое устройство разработки: POCO F6 (ARM64).

## Сейчас в репозитории

- Jetpack Compose launcher UI.
- Выбор GGUF-файла через Android Storage Access Framework с сохранением URI permission.
- Потоковый импорт GGUF в приватное хранилище приложения с проверкой magic header и свободного места.
- AccessibilityService зарегистрирован; чтение текста окон по умолчанию отключено.
- Типизированная модель действий агента (NexusAction).
- Fail-closed policy: пустые/некорректные параметры блокируются; нажатия и ввод требуют подтверждения; отправка сообщений, звонки, удаление и покупки пока полностью заблокированы до появления проверенных исполнителей.
- GitHub Actions собирает debug APK и публикует его как artifact.

## Пока не реализовано

- Встроенный llama.cpp runtime / JNI и реальный запуск GGUF (следующий крупный этап).
- Wake-word detector для «NEXUS».
- Локальное распознавание речи (ASR) и синтез речи (TTS).
- Голосовой диалог, диспетчер подтверждений и полноценное исполнение действий.
- Фоновый microphone foreground service.

Не считать приложение готовым голосовым агентом до реализации и проверки этих компонентов на реальном POCO F6.

## Сборка

CI использует JDK 17, Android SDK 36 и Gradle 8.11.1.
Выходной файл: app/build/outputs/apk/debug/app-debug.apk.

## Безопасность

LLM не получает доступ к произвольному shell-коду. Любое действие должно проходить через типизированную модель и policy gate. Внешние, финансовые и потенциально необратимые действия требуют явного подтверждения пользователя.
