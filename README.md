# NEXUS AI

Локальный Android-помощник с управлением телефоном. Целевое устройство разработки — POCO F6 / Android 16.

## Текущий статус

**Ранняя стадия разработки. Это ещё не автономный голосовой агент и не готовый APK.**

Уже добавлено:
- базовый Android UI на Jetpack Compose;
- выбор GGUF-файла через системный Storage Access Framework с сохранением URI-разрешения;
- регистрация AccessibilityService и XML-конфигурация;
- минимальный безопасный обработчик нажатия по точному видимому тексту;
- GitHub Actions workflow для сборки debug APK на JDK 17 / Gradle 8.11.1.

Пока не реализовано:
- запуск GGUF-модели и llama.cpp JNI;
- постоянное обнаружение ключевого слова «NEXUS»;
- локальный ASR и TTS pipeline;
- планировщик инструментов, подтверждения действий голосом;
- проверенная сборка и установка на POCO F6.

## Планируемая архитектура

1. **Wake word:** локальный детектор «NEXUS».
2. **ASR:** локальное распознавание русской речи.
3. **LLM:** GGUF-модель через llama.cpp.
4. **Planner:** формирование типизированного плана действий.
5. **Policy layer:** allow-list, проверка контекста и подтверждение критических действий.
6. **Android bridge:** AccessibilityService и официальные Android API.
7. **TTS:** озвучивание ответов и запросов подтверждения.

## Целевое устройство и модель

POCO F6, Snapdragon 8s Gen 3, 8 ГБ физической RAM. Виртуальное расширение памяти не считается эквивалентом физической RAM. Начальная цель — компактная instruct-модель 3B–4B в GGUF Q4; размер контекста и модель будут окончательно выбраны после измерений производительности и потребления памяти на устройстве.

## Безопасность и приватность

- LLM не получает произвольный доступ к shell или исполнению кода.
- Команды выполняются только через типизированный allow-list.
- Отправка сообщений, удаление данных, платежи, публикации и другие внешние/необратимые операции должны требовать явного подтверждения.
- AccessibilityService включается пользователем вручную в настройках Android.
- Микрофонный режим будет запускаться только с соблюдением ограничений Android на foreground services и с видимым системным уведомлением.

## Сборка

Открыть проект в Android Studio с JDK 17 и Android SDK 36. GitHub Actions запускает `:app:assembleDebug` на push и pull request в `main`; APK публикуется как workflow artifact после успешной сборки. Gradle wrapper пока не добавлен.
